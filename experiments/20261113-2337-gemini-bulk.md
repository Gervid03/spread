# bulk: Budget the yard and count quotes in flight for bulk orders

- **Agent / branch / commit:** gemini · exp/gemini-bulk · 
- **Date:** 2026-11-13 23:37
- **Idea from:** IDEAS.md #7

## Why we tried it
A bulk order's requests arrive simultaneously and are all quoted before any is won. This bypassed the `backlog` gate which only counts won orders, leading to over-staffing in the same town. By budgeting quotes in flight and safely sorting within batches, we avoid taking too many simultaneous orders and causing late deliveries.

## What changed
`yard_cap_ratio` (default `0.0`): per pickup town and deadline day, won-and-unstaffed orders plus quotes in flight x `price_target_win` may not exceed max(`backlog_min`, ratio x supply). 
Requests in a batch (or exact same minute) are sorted to quote the safest cars first (slow option, short drive, more destination supply).
Run with: `uv run lab eval -s yard_cap_ratio=0.12 --name bulk-dev`
